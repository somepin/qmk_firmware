# ChipQAZ

A handwired unauthorized QAZ clone made of stacked chipboard held together by sobo glue.

Credits to [tominabox1](https://github.com/tominabox1) and whydobearsxplod for the OG [QAZ](https://www.cbkbd.com/product/qaz-keyboard-kit).

-   Keyboard Maintainer: [somepin](https://github.com/somepin)
-   Hardware Availability: wherever you can get some chipboard, glue, wires, and a MCU

Make example for this keyboard (after setting up your build environment):

    qmk compile -kb chipqaz -km default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
